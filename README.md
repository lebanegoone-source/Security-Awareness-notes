# Security-Awareness-notes
this repo contains notes and tips for improving cyber security awareness
##**Password security**
-Use of long and strong passwords.
-Frequent updating of passwords by a user
-Prevent sharing paaswords with other people
-Avoid repeating the same password.
##**Safe-Browsing.md**
-Avoid clicking on suspicious links.
-Install an updated anti virus scanner.
-Ensure that the browser is frequently patched.
##**Phishing Awareness**
-Prevent clicking on unknown links and sender addresses.
-Use Multi-Factor Authentication.
-DNS filtering to block unknown malicious domains.
-Ignore or inquire about requests for credentials, money transfers and verification codes.
